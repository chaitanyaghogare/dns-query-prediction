# Agent Instructions

## Project
DNS Cache Optimization and Query Prediction System.

## General Rules
- Work only within this project directory.
- Do not delete files unless explicitly instructed.
- Do not overwrite working implementations without checking them first.
- Prefer simple, explainable solutions over unnecessary complexity.
- Keep the project modular.
- Write tests for important functionality.
- Update documentation when architecture changes.

## Technology
- Primary language: Python
- ML: scikit-learn / XGBoost / other libraries only when justified
- Use virtual environments.
- Keep dependencies in requirements.txt.

## Directory Rules
- src/ → source code
- data/ → datasets
- models/ → trained models
- tests/ → tests
- experiments/ → experiments and benchmarks
- docs/ → documentation

## Before Major Changes
Explain:
1. What is being changed
2. Why it is needed
3. What files will be affected

## Important
The goal is not merely to build an ML model.
The ML model must demonstrably improve DNS cache performance.
